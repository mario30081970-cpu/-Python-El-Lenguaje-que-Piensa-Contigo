    Sección 2

    Laboratorio de Tipado Dinámico

    Python gestiona los tipos de datos de forma automática e invisible: es más rápido y menos propenso a errores. ¡Python piensa por ti!

    🔮 Asignación invisible

    Escribe el valor de cada variable. Python analizará el contenido y asignará el tipo por sí solo.

    🖥️ Consola de Python

    # Escribe un valor arriba para ver el resultado…

    ⚖️ Ayer vs. Hoy

    Ayer · PSeInt (tipado estático)

    Definir nombre Como Cadena;
Definir edad Como Entero;
Definir altura Como Real;
Definir es_estudiante Como Logico;

nombre <- "Ana";
edad <- 17;

    ⚙️ Debes declarar el tipo manualmente y pensar en cómo funciona la máquina.

    Hoy · Python (tipado dinámico)

    nombre = "Ana"
edad = 17
altura = 1.65
es_estudiante = True

print(type(nombre))   # <class 'str'>

    💡 Asignas un valor y Python se encarga del resto. Te concentras en resolver el problema.

    🔀 Prueba de Flexibilidad Total

    En lenguajes estáticos el tipo es fijo e inmutable. En Python, una variable puede cambiar de tipo en plena ejecución sin generar errores. Toca al menos 2 valores distintos.
